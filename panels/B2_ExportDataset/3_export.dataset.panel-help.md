<h5>Export data</h5>
The current work data set can be downloaded. Select the file type in the
dropdown menu at the top left and press the "DOWNLOAD" button.  Several file
types are available in which the data can be saved. <br>
<ul>
   <li>
      txt<br>
      A tab delimited text file.
   </li>
   <li>
      csv<br>
      A comma separated text file.
   </li>
   <li>
      RData<br>
      An RData binary file.
  </li>
  <li>
     RDS<br>
     An RDS binary file.
  </li>
</ul>
Note, "RData" and "RDS" files are R only. They can be loaded into R with the load
or readRDS function. They have the advantage that no information is lost. The
txt files (txt and csv) are not able to store some information.
